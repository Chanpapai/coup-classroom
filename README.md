# COUP : ห้องเรียน

เกมกระดานหลายคนบนเว็บ 2–6 คน เล่นบนมือถือ ใช้ของฟรีทั้งหมด
Frontend เป็น HTML/CSS/JS ล้วน ไม่ต้อง build อะไรเลย · Backend ใช้ Supabase

---

## 1. โครงสร้างไฟล์

```
coup-classroom/
├── index.html              หน้าเว็บทั้งหมด (ทุกหน้าจออยู่ในไฟล์เดียว)
├── css/
│   ├── base.css            สี ฟอนต์ และการล็อกหน้าจอ
│   ├── components.css      ปุ่ม การ์ด กล่องโต้ตอบ
│   └── screens.css         เลย์เอาต์แต่ละหน้า
├── js/
│   ├── config.js           ⚠️ ไฟล์เดียวที่คุณต้องแก้ (คีย์ Supabase + ชื่อไฟล์รูปการ์ด)
│   ├── net.js              ล็อกอิน เรียกเซิร์ฟเวอร์ ฟัง Realtime
│   ├── ui.js               ตัวช่วยวาดการ์ด/ช่องผู้เล่น + เนื้อหาหน้าสอนเล่น
│   ├── sound.js            เสียงสังเคราะห์ ไม่มีลิขสิทธิ์
│   └── app.js              ตัวควบคุมหน้าจอ
├── assets/cards/           📷 วางรูปการ์ดของคุณที่นี่
├── src/
│   ├── engine.js           ⭐ กติกาเกมทั้งหมด
│   └── handler.js          ส่วน HTTP ของ Edge Function
├── supabase/
│   ├── schema.sql          ตาราง + สิทธิ์การเข้าถึง
│   └── functions/game/index.ts   ไฟล์ที่สร้างจาก src/ (อย่าแก้ตรงๆ)
├── tests/engine.test.mjs   ชุดทดสอบกติกา 47 ข้อ
└── build-function.mjs      รวม src/ เป็นไฟล์เดียวให้ Supabase
```

**หลักการสำคัญ:** กติกาทั้งหมดอยู่ที่ `src/engine.js` ซึ่งรันบนเซิร์ฟเวอร์
หน้าเว็บทำได้แค่ "ขอ" ให้เซิร์ฟเวอร์ทำอะไรบางอย่าง แล้ววาดผลลัพธ์
เปิด DevTools แก้ตัวเลขทองในเบราว์เซอร์ก็ไม่มีผล เพราะเซิร์ฟเวอร์ไม่เชื่อ

## 2. ตั้งค่า Supabase (ทำครั้งเดียว ~10 นาที)

### 2.1 สร้างโปรเจกต์
ไปที่ [supabase.com](https://supabase.com) → New project
ตั้งชื่ออะไรก็ได้ เลือก region **Southeast Asia (Singapore)** จะเร็วที่สุด
ไม่ต้องใส่บัตรเครดิต

### 2.2 สร้างตาราง
เมนูซ้าย **SQL Editor** → New query → ก็อปทุกบรรทัดใน `supabase/schema.sql` มาวาง → **Run**
ควรขึ้น Success

### 2.3 เปิดการล็อกอินแบบนิรนาม
**Authentication → Sign In / Providers → Anonymous Sign-Ins → เปิด → Save**

ขั้นนี้ห้ามข้าม ผู้เล่นจะได้ไม่ต้องสมัครสมาชิก และเป็นตัวที่ทำให้ระบบรู้ว่า
"การ์ดใบไหนของใคร" ตอนต่อเน็ตกลับเข้ามาใหม่

### 2.4 ติดตั้ง Edge Function
**Edge Functions → Deploy a new function → Via Editor**

- ชื่อฟังก์ชัน: `game` (ต้องชื่อนี้เป๊ะๆ)
- ลบโค้ดตัวอย่างทิ้งให้หมด แล้วก็อปทุกบรรทัดใน `supabase/functions/game/index.ts` มาวาง
- กด **Deploy**

จากนั้นเข้าไปที่ฟังก์ชัน `game` → **Settings** → ปิด **Verify JWT**
(เราตรวจ token เองในโค้ดอยู่แล้ว ถ้าเปิดไว้ browser จะติด CORS)

### 2.5 คัดลอกคีย์มาใส่
**Project Settings → API** จะเห็น 2 อย่าง คัดลอกมาใส่ใน `js/config.js`

```js
export const SUPABASE_URL = 'https://abcdefgh.supabase.co';
export const SUPABASE_ANON_KEY = 'eyJhbGciOi...';
```

> anon key เปิดเผยได้ ปลอดภัย ห้ามเอา `service_role` key มาใส่ตรงนี้เด็ดขาด

## 3. รันบน Chromebook

เปิด Terminal (ถ้ายังไม่มี: Settings → Advanced → Developers → Linux development environment)

```bash
cd coup-classroom
python3 -m http.server 5173
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:5173`

> เปิดไฟล์ `index.html` ตรงๆ ด้วย `file://` **ไม่ได้** เพราะเบราว์เซอร์บล็อก ES modules

ทดสอบหลายคน: เปิดหน้าต่าง **Incognito** เพิ่ม (แต่ละหน้าต่างต้องเป็นคนละคน)

## 4. Deploy ฟรีด้วย Vercel

### 4.1 ขึ้น GitHub
```bash
git init
git add .
git commit -m "COUP ห้องเรียน"
git branch -M main
git remote add origin https://github.com/USERNAME/coup-classroom.git
git push -u origin main
```

### 4.2 ต่อกับ Vercel
[vercel.com](https://vercel.com) → Sign up ด้วย GitHub → **Add New → Project** → เลือก repo

- Framework Preset: **Other**
- Build Command: เว้นว่าง
- Output Directory: เว้นว่าง
- Root Directory: `./`

กด **Deploy** รอ ~30 วินาที จะได้ลิงก์ `https://ชื่อโปรเจกต์.vercel.app`

ไม่ต้องตั้ง Environment Variables เพราะคีย์อยู่ใน `js/config.js` แล้ว
(ทำแบบนี้ได้เพราะ anon key ตั้งใจให้เปิดเผยอยู่แล้ว)

## 5. วิธีอัปเดตเกม ⭐

Vercel ผูกกับ GitHub ไว้แล้ว **แค่ push โค้ดขึ้นไป Vercel จะ deploy ให้เองใน 1–2 นาที**

### แก้หน้าตา / ข้อความ / กติกาฝั่งหน้าเว็บ
แก้ไฟล์ใน `index.html`, `css/`, `js/` แล้ว

```bash
git add .
git commit -m "อธิบายสั้นๆ ว่าแก้อะไร"
git push
```

เข้า Vercel → แท็บ **Deployments** รอขึ้น **Ready** → เปิดเว็บแล้วกด **Ctrl+Shift+R**
(มือถือ: ปิดแท็บแล้วเปิดใหม่ หรือล้างแคชเบราว์เซอร์)

### แก้กติกาเกม
กติกาอยู่ที่ `src/engine.js` แก้แล้วต้องทำ 3 ขั้น

```bash
node tests/engine.test.mjs   # 1. เช็คว่าไม่พังกติกาเดิม
node build-function.mjs      # 2. สร้าง index.ts ใหม่
git add . && git commit -m "แก้กติกา" && git push
```

**ขั้นที่ 3** เอา `supabase/functions/game/index.ts` ที่เพิ่งสร้าง ไปวางทับใน
Supabase → Edge Functions → `game` → Deploy อีกครั้ง

> git push อย่างเดียวไม่พอสำหรับกติกา เพราะ Edge Function อยู่บน Supabase ไม่ได้อยู่บน Vercel

### แก้ตารางฐานข้อมูล
ต้องไปรัน SQL ใน Supabase Dashboard เอง ไม่ได้ตามไปกับ git

### สรุปว่าอะไรอยู่ที่ไหน
| แก้อะไร | ต้องทำอะไร |
|---|---|
| หน้าตา ข้อความ สี ปุ่ม | `git push` อย่างเดียว |
| รูปการ์ด | `git push` อย่างเดียว |
| กติกาเกม (`src/engine.js`) | `git push` + Deploy Edge Function ใหม่ |
| ตาราง/สิทธิ์ (`schema.sql`) | รัน SQL ใน Supabase |

## 6. เปลี่ยนรูปการ์ดเป็นรูปที่คุณทำเอง

วางไฟล์ใน `assets/cards/` ใช้ชื่อตามนี้ แล้วจบ ไม่ต้องแก้โค้ดที่อื่นเลย

```
duke.png · captain.png · ambassador.png · contessa.png · assassin.png · card-back.png
```

- สัดส่วนที่พอดีคือ **5:7** เช่น 500×700 px
- รูปจะถูกแสดงแบบ `contain` — เห็นเต็มรูป ไม่ครอป ไม่ยืด ไม่มีอะไรวาดทับ
- ใช้ `.jpg` หรือ `.webp` ได้ แค่ไปแก้นามสกุลใน `js/config.js` ให้ตรง
- ยังไม่มีรูปก็เล่นได้ เกมจะใช้ไอคอนสำรองให้

จากนั้น `git add . && git commit -m "ใส่รูปการ์ด" && git push`

## 7. ทดสอบ 6 คน

**วิธีเร็วสุด** เปิดบนเครื่องเดียว 6 หน้าต่าง

1. หน้าต่างปกติ 1 บาน
2. Incognito อีก 5 บาน (Ctrl+Shift+N) — **แต่ละบานต้องเป็นหน้าต่างแยก ไม่ใช่แท็บ**
   เพราะ Incognito หลายแท็บในหน้าต่างเดียวกันใช้ storage ร่วมกัน จะกลายเป็นคนเดียวกัน
3. บานแรกกดสร้างห้อง จำรหัส 6 ตัว
4. บานที่เหลือกรอกรหัสเข้าห้อง
5. **กดพร้อมให้ครบทุกบาน** → นับถอยหลัง 10 วินาที → เกมเริ่มเอง

**ทดสอบจริงบนมือถือ** ให้ทุกคนเข้าลิงก์ `.vercel.app` เดียวกัน

**สิ่งที่ควรลองทดสอบ**
- ปิดเน็ตมือถือ 10 วินาทีแล้วเปิดใหม่ → ต้องกลับเข้าเกมได้เอง
- รีเฟรชหน้ากลางเกม → ต้องเห็นการ์ดเดิมและทองเดิม
- ปล่อยให้หมดเวลา Challenge → Action ต้องเดินต่อเอง
- เล่นจนมีคนตาย → คนนั้นต้องไม่มีปุ่มอะไรกดได้เลย

## 8. สี่ข้อที่แก้ อยู่ตรงไหนบ้าง

**ข้อ 1 — ต้องกดพร้อมครบทุกคนถึงจะเริ่ม**
ไม่มีปุ่ม "Host เริ่มเกม" แล้ว ทุกคนต้องกดพร้อม → นับถอยหลัง 10 วินาทีเต็มจอ → เกมเริ่มเอง
ถ้าระหว่างนับมีคนยกเลิกพร้อม หรือมีคนใหม่เข้าห้อง การนับจะยกเลิกทันที
→ `src/engine.js` ฟังก์ชัน `evSetReady`

**ข้อ 2 — เอาโต๊ะกลางออก ขยายให้กว้าง**
พื้นที่ตรงกลางเป็นกระดานผู้เล่นเต็มความกว้าง ไม่มีกรอบโต๊ะ
ข้อมูลกอง/คลังย่อเป็นแถบบางๆ ด้านล่าง
→ `css/screens.css` ส่วน `.board`

**ข้อ 3 — คนตายดูอย่างเดียว**
กันไว้ 3 ชั้น
1. เซิร์ฟเวอร์ปฏิเสธทุกคำสั่งจากคนที่ `alive === false` (`requireTurn`, `evRespond`)
2. หน้าเว็บซ่อนแถบ Action ทั้งแถบ แล้วขึ้นแถบ "ดูเกมได้อย่างเดียว" แทน
3. CSS `.is-spectator` บล็อกกล่องโต้ตอบไม่ให้เด้งขึ้นมาเลย

**ข้อ 4 — ล็อกหน้าจอ ไม่ให้เลื่อน**
`position: fixed` + `100dvh` + `overscroll-behavior: none` + ปิดการซูม
หน้าเกมใช้ CSS Grid ที่มีเพียงแถวเดียวยืดได้ (กระดาน) ที่เหลือสูงคงที่ จึงไม่มีวันล้นจอ
เลื่อนได้เฉพาะหน้าสอนเล่นและแผงบันทึก ซึ่งเลื่อนอยู่ในกรอบตัวเอง
→ `css/base.css` และ `css/screens.css`

## 9. เจอปัญหาบ่อยๆ

**หน้าขาว ไม่มีอะไรขึ้น**
เปิด DevTools (F12) ดูแท็บ Console ส่วนใหญ่คือยังไม่ได้ใส่คีย์ใน `js/config.js`

**"เข้าสู่ระบบไม่สำเร็จ"**
ยังไม่ได้เปิด Anonymous Sign-Ins ในข้อ 2.3

**กดปุ่มแล้วขึ้น "ไม่รู้จักคำสั่งนี้" หรือ CORS error**
Edge Function ยังไม่ได้ deploy หรือชื่อไม่ใช่ `game` หรือยังไม่ได้ปิด Verify JWT

**เพื่อนกดพร้อมแล้วแต่จอเราไม่อัปเดต**
Realtime ยังไม่เปิดให้ตาราง ลองรัน `supabase/schema.sql` ซ้ำอีกรอบ

**แก้โค้ดแล้ว push แล้ว แต่เว็บยังเป็นของเดิม**
แคชเบราว์เซอร์ กด Ctrl+Shift+R หรือเปิด Incognito ดู
ถ้าแก้กติกา อย่าลืม Deploy Edge Function ใหม่ด้วย (ข้อ 5)

**ห้องหายไปเอง**
ห้องที่ไม่มีความเคลื่อนไหวเกิน 12 ชั่วโมงจะถูกลบอัตโนมัติ เพื่อไม่ให้ free tier เต็ม

## 10. ค่าใช้จ่าย

ฟรีทั้งหมด ไม่ต้องใส่บัตรเครดิต

| บริการ | โควต้าฟรี | เกมนี้ใช้ประมาณ |
|---|---|---|
| Supabase Database | 500 MB | ห้องละไม่ถึง 20 KB |
| Supabase Edge Functions | 500,000 ครั้ง/เดือน | เกมละ ~150 ครั้ง |
| Supabase Realtime | 200 การเชื่อมต่อพร้อมกัน | 6 คน = 6 การเชื่อมต่อ |
| Vercel Hosting | 100 GB/เดือน | หน้าเว็บหนักไม่ถึง 100 KB |

พูดง่ายๆ คือเล่นได้ประมาณ 3,000 เกมต่อเดือนโดยไม่เสียเงิน
